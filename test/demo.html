Configuring builds

Project documentation · draft

In order to be able to configure the build, you first of all need to create a settings file in the root directory of the project. The settings file is the file that declares which plugins are applied to the build and it is also the file that lists the projects that make up the build.

Declaring plugins

Plugins are declared in the settings file. Each plugin is identified by its id, and plugins are resolved from the repositorys that are declared in the same file. Plugins are declared in the settings file, never in a build file.

Once a plugin is applied, it contributes a schema that describes the software types that the build files can use. A build file then picks one of those software types and configures it.
